# Acme Tasks

React 19 + TypeScript app on shadcn/ui (Radix), Tailwind CSS v4, TanStack
Query, and Zustand. React Compiler is enabled in `vite.config.ts`.

- shadcn primitives live in `src/components/ui`; feature code lives in
  `src/features/<feature>`.
- Validate with `npm run typecheck`. Do not install packages.
