# Product rules

Decisions owned by the product team. Link the rule id from code that enforces it.

## PR-4 Task titles

Task titles are limited to 120 characters in every client.

## PR-7 Deleting tasks from the list

Tasks that are in progress cannot be deleted from the task list. Users first
move the task back to To do.

Reason: time is tracked against in-progress tasks, and deleting one discards
billable hours that have not been invoiced yet.

## PR-9 Done tasks

Done tasks stay visible in the list, de-emphasized, until the project is
archived.
