# Team skills (fork of React Skills)

This folder is the editable source of the skills our apps install into
`.agents/skills/`. We publish from here.

Before changing a skill:

1. Read [docs/technology-stack.md](docs/technology-stack.md).
2. Read [docs/adding-a-skill.md](docs/adding-a-skill.md).
3. Read the target skill's `SKILL.md`, references, examples, `registry.json`,
   and `README.md`.

Validate with `npm run typecheck` from the app root; it type-checks every
skill example.
